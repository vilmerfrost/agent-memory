# Parked ideas (shipit)

- Flake Hunter: rerun flaky tests and name the flake. Revisit when flaky failures block a merge twice in a week.
- Ghost Hunter: Ghost Reviewer × Flake Hunter in one review. Revisit once Ghost Reviewer has shipped.
- PR Weather: a one-line merge forecast per PR. Revisit when the review queue passes 20 open PRs.
- Standup Radio: Diff Diary as a 60-second audio briefing. Revisit if Diff Diary gets read every day.
- Merge Concierge: auto-merge green, approved PRs. Revisit when you trust the checks enough to sleep through a merge.
- Commit Haiku: squash messages as haiku. Revisit never, unless a release needs a joke.
