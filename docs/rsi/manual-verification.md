# Separately identified manual verification

An explicitly approved extra run can use `amem rsi night --manual-run-id manual-<unique-id> --config config/rsi-night.subscription.json --json`. The configured API and subscription caps remain unchanged. The CLI retains database write guards, requires all latest prerequisite routines to have succeeded within their freshness limits (25 hours by default), and checks configured credentials. Scheduled jobs keep their calendar-matching gate unchanged. A manual run is not proof that the future scheduled prerequisite chain passed.

The calendar night remains in `report.night`; `report.manual_run.id` identifies the execution. Experiments and coverage consumption use that unique run key. Reports go under `sandbox/manual-runs/<id>/nights/<night>/report.json`, never the scheduled report path. Checkpoints use the manual key and are explicitly excluded from the scheduled incremental cursor query. The same global run lock prevents overlap. A manual run does not reconcile unrelated orphans; unwind touches its own experiment run key and selected candidates only.

Manual experiments retain their real verdicts and immutable evaluation artifacts. They never create approval proposals, even when a verdict improves. Existing candidate/history bookkeeping remains active, so newly measured evidence may inform later candidate selection. Manual execution does not consume the scheduled date or change its schedule, budget, criteria, approval gates or saved report. The scheduled run will still execute normally and can select different candidates because fresh evidence exists.

Generate a separate diagnostic brief with `rsi_brief.make_brief(root=<sandbox/manual-runs/id>, night=<calendar-night>)`. Do not use `brief-job` on that manual root to publish over a scheduled dashboard row: its dashboard identity is the calendar night. Manual verification is reported separately in chat and local artifacts. The existing nightly dashboard and morning-delivery chain remain scheduled. A full manual-run dashboard is outside this narrow runner change.

Tests prove scheduled report bytes/checkpoint remain unchanged, the manual coverage/experiment keys are distinct, no manual proposal is created, a subsequent scheduled night still reads the canonical cursor, path traversal is rejected, and manual identities cannot overwrite an existing completed execution.
